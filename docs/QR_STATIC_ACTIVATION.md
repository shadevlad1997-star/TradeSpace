2026-10-01. Только локально. Исходный HEAD: `b50f15e8312db36272c7c2eb500092762473e8b5`; ветка `codex/qr2-bank-drafts`; исходное дерево чистое.

## Реализовано

Новое требование владельца заменяет прежнее обязательное сохранение короткой ссылки как неактивного черновика. В режиме «Статический QR» поддерживаемое изображение сохраняется сразу active/enabled при обычном выбранном активном статусе. Явное отключение сохраняется. Существующие записи не включаются массово: кнопка «Включить» работает без повторной загрузки.

Тип из payload имеет источник `payload`; заявленный трейдером тип короткой ссылки — `trader_selection`. Источник сохраняется в существующем AuditLog при создании/редактировании/включении вместе с SHA-256 payload и в QR snapshot новых заявок. Банковская проверка не заявляется, URL не изменяется. Старые snapshots не переписываются. Схема БД и миграции не изменены.

Сохранены: строгий HTTPS-адрес и путь NSPK, PNG/JPEG, один читаемый QR, лимиты файла/пикселей, допустимые параметры, валюта RUB и существующие проверки суммы/банковского/контрольного полей. Динамический и неподдерживаемый типы, фиксированная сумма, посторонняя ссылка и нечитаемое изображение отклоняются. Контрольное поле проверяется по прежним правилам; это не проверка подлинности банком.

Порядок блокировок и уникальность активного QR + сумма + валюта, включая дубликаты между Merchant/Aggregator API, сохранены. Активация сама не создаёт Deposit, резерв или денежное движение. Подтверждение остаётся ручным. Финансовые формулы и правила споров не менялись.

## Приёмка

| Сценарий | Результат |
|---|---|
| Явный статический и короткий QR | active/enabled после создания и повторного входа/GET. |
| Короткая ссылка без type | Принимается по статическому выбору; источник trader_selection, URL неизменен. |
| Старый короткий QR | Включение без файла; GET ничего не включает; соседний намеренно отключённый QR остаётся отключённым. |
| Динамический/неподдерживаемый/фиксированная сумма/неверная валюта или адрес | Отказ несмотря на выбор статического режима. |
| Нечитаемое изображение | Понятная ошибка, реквизит не создаётся. |
| Права и CSRF | Чужой трейдер не включает реквизит; без CSRF отказ; Merchant не получает preview. |
| Лимиты/баланс/статус | Отказы до резерва в обоих API. |
| Конкурентная выдача и дубликаты | Одна одинаковая заявка создаётся, вторая получает 409; другая сумма разрешена. Состояние pending, автоматической оплаты нет. |
| Snapshot | Выданная ссылка и её источник не меняются после изменения реквизита. |
